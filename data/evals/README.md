# Card data

One JSON per rendered card; the ids must match `BENCHES` in `evals.js`.

- `economic-arena.json` — our own run (Exploitability card). Regenerate with
  `economic-arena/export_card.py --run-id <id> --out evals/data/economic-arena.json`.
- `treasury-bench.json` — our own run (Treasury-Bench card). Regenerate with
  `treasury-bench/scripts/export_card.py` (defaults to this file). Includes the
  buffer-heuristic baseline; all-cash is referenced in the blurb only.
- `terms-bench.json`, `vending-bench-2.json` — snapshots of published third-party
  results, regenerated by `tools/fetch_terms_bench.py` / `tools/fetch_vb2.py`.
  Displayed with attribution; each card records its own snapshot date.

Not present by design: a card built from the arXiv:2603.20925 result tables. Those
numbers could not be reconciled against the run outputs, so they are not served
from this repo. See big-brain `projects/economic-arena/`.
