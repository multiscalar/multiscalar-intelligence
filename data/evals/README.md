# Card data

One JSON per benchmark page; the ids must match `BENCHES` in
`lib/evals/benches.ts`.

## In the index

`terms-bench.json`, `e-commerce-bench.json`, `econevals.json`,
`auction-bench.json`, `coffeebench.json`, `treasury-bench.json`: the
benchmarks the Economic Intelligence Index averages (`INDEX_BENCHES`), each
ranked by its 0-100 index score from an eii index run. Regenerate all six
from that run's `index.json`:

    python3 tools/export_eii_cards.py <index.json>

`index.json` is an artifact of the index run in MLflow (experiment
`eii/prod`, run `eii-prod@<version>`), or `runs/eii-prod/index.json` after
`make show SUITE=index/eii-prod.yaml` in github.com/multiscalar/eii. Titles,
questions, blurbs, paper links and the page copy (`notes`: what it
measures, how its metric becomes 0-100, the unscaled results) live in the
script, with each model's unscaled result (`raw`, the bar chart's hover)
and reference lines (`refs`). Current: eii-prod
2026-10.3 (2026-11-03).

The same command writes `index.json`, the index preview's scores: the run
rescored under the C1-C5 dimension design in the private eii repo
(`index/eii-dimensions.yaml`; this repo is public and publishes no weights)
(each dimension a weighted mean of the benchmark scores, overall the mean
of the dimensions), plus each model's inference cost for the run. Keep that
YAML in step with the eii suite's `dimensions`; the script refuses to run if
a contribution's metric, floor or ceiling differs from the run's.

EconSec is in the index but not yet scored: it shows as a "coming soon" card
(`lib/evals/upcoming.ts`).

## Outside the index

Earlier boards, kept as pages but not shown in the index section:

- `zerosum-bench.json` - our own run (slug was `economic-arena` until
  2026-09-11). Regenerate with
  `zerosum-bench/export_card.py --run-id <id> --out data/evals/zerosum-bench.json`
  from github.com/multiscalar/zerosum-bench.
- `vending-bench-2.json` - a snapshot of Andon Labs' published results,
  regenerated by `tools/fetch_vb2.py`.
- `treasury-scatter.json` - the earlier Treasury-Bench board's scatter
  (`tools/export_treasury_card.py`); its chart is no longer on the page.

Not present by design: a card built from the arXiv:2603.20925 result tables.
Those numbers could not be reconciled against the run outputs, so they are
not served from this repo. See big-brain `projects/zerosum-bench/`.
